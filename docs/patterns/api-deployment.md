# Private REST and live GraphQL services

Each API owns `infra/app.ts` and `infra/stack.ts`. The sibling hub's pinned `platform-cdk/node_modules` is the shared deployment toolchain; its installed CDK, TypeScript, tsx and Vitest are used by the real `infra:synth`, `infra:typecheck` and `infra:test` scripts. No API runtime imports infrastructure or needs CDK. Keep all four checkouts as siblings. Set the non-secret inputs listed in each `infra/.env.example` explicitly in the process; the apps never load env files. For offline verification use the installed toolchain binaries, `TSX_TSCONFIG_PATH=infra/tsconfig.json` and `node --import ../graph-rest-react-stack/platform-cdk/node_modules/tsx/dist/loader.mjs infra/app.ts`, with `CDK_OUTDIR=cdk.out`, fake identifiers and AWS credential/config inputs disabled. Deploy-time SSM references avoid account lookups during synthesis.

Deploy the foundation first. Its versioned parameters supply two private subnet IDs, task security groups, listener ARNs, ECS cluster, role ARNs, logs, Cognito, table and image repository references. Graph's internet-facing HTTPS listener forwards to port 4000; REST's internal listener forwards to port 3000. Security groups allow graph ALB → graph tasks → REST ALB → REST tasks, with no public task IPs and no general VPC ingress to REST. Every cloud API task is explicitly `APP_MODE=live`, requiring Cognito JWTs. REST explicitly selects DynamoDB with its foundation task role; GraphQL has no database grant. Local Compose remains a separate demo configuration.

Each service uses 256 CPU units and 512 MiB, container and ALB `/health` checks, rollback circuit breakers, and the retained rotating-key-encrypted foundation log group with 14-day retention. ECR repositories enforce immutable tags; `API_IMAGE_TAG` must be the complete service Git SHA. Only graph's execution role has the foundation's provider secret read permissions. Selected OpenAI/Anthropic and Ticketmaster keys are ECS Secrets Manager references; key values are never configuration inputs or synthesized literals. Providers default to deterministic mocks even with real Cognito, so enabling a paid provider remains explicit. The task roles never read provider secrets. Telemetry is off unless a later operator configuration enables an exporter.

Graph has one desired task and deployment percentages 0/100, preventing overlapping owners of process-local generations. Replacement creates downtime; active streams/jobs are interrupted and cannot migrate to the next process. A load-balancer drain lasts 30 seconds, not a guarantee that generation work completes. The deployment circuit breaker can restore the prior task revision but cannot restore in-memory jobs. REST uses a conventional 100/200 rolling update with durable data in DynamoDB. Each stack creates a CPU alarm at greater than 85 percent for three one-minute periods, with no notification action. Investigate load, throttling and recent changes; do not scale GraphQL above one task without distributed generation state. No cloud deployment, alarm delivery, secret injection or live Cognito behavior has been verified.

Offline template tests check routing, private placement, bounded resources, imported task/execution roles, real auth, secret injection and alarms. Foundation tests check immutable repositories and security-group-only REST ingress. These prove template contracts rather than the existence of cloud certificates, secrets, subnets or permissions for a deployment principal.
